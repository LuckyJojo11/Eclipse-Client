# Eclipse Client Website

This repository contains the info and download page for Eclipse Client.

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Open:

```text
http://localhost:1420
```

## Build

Create the production build:

```bash
npm run build
```

The finished website will be generated in the `dist/` folder.

## GitHub Pages

The Vite base path is set to:

```text
/Eclipse-Client/
```

That matches this GitHub Pages URL:

```text
https://luckyjojo11.github.io/Eclipse-Client/
```
